# snow_golem 0.1.0 (first preview)

snow_golem is a VS Code extension that lets an AI assistant make Minecraft Bedrock particle effects inside
your resource pack. You describe the effect, the AI builds it, and you watch it in Snowstorm.

This is the first public version. It works, but it has not been used on many real addons yet. Please try it
on a copy of your pack and tell me what breaks.

## What you can do

- Ask for an effect in plain words, like "a purple portal for the shrine" or "a cyan hit spark when the
  boss slams". The AI starts from one of 6 presets (impact, explosion, aura, trail, vortex, glitch) or
  designs its own layers.
- Watch the effect in Snowstorm while the AI changes it. The preview updates each time a file changes.
- Add the effect to an entity and play it at a moment in an animation, on a locator. snow_golem checks
  that the locator exists in the model.
- Find mistakes that Snowstorm and the game accept without warning: misspelled component names, broken
  Molang, `particle_random_5`, UVs outside the texture, and effects that spawn files that don't exist.
- See how many particles an effect keeps alive across all its layers, rated for mobile or desktop.

## How effects are built

A Bedrock particle file can only use one texture and one material, so a good effect is usually several
files. snow_golem puts each effect in its own folder. The main file controls the timing and starts the
other layers. Only the main file loops, so stopping it stops the whole effect. Opening the main file in
Snowstorm plays every layer together.

## Your files are safe

The AI cannot save anything until you agree. Every change comes back as a diff first. When you approve it,
snow_golem backs up any file it overwrites to `.snow_golem/backups/`. It never writes outside your project
folder, and it refuses to save over a file that changed or has unsaved edits.

## Install

1. Download `snow-golem-0.1.0.vsix` from this release.
2. In VS Code: Extensions view, `…`, *Install from VSIX…*. Snowstorm is installed with it.
3. Open your addon folder and click `❄ snow_golem` in the status bar to copy the setup for your AI app.

Works with Claude Code, Claude Desktop, VS Code's agent mode, and other apps that support MCP.

## Known limits

- Tested with 66 automated checks and a renderer. It has not been tested in-game on many packs yet.
  The layer timing in particular needs checking in Bedrock.
- The performance ratings are estimates, not official Mojang limits.
- The AI cannot see the effect yet, so you have to tell it what looks wrong. A tool that lets it look
  at rendered frames is planned next.
- Custom textures work if they are already in your pack, but snow_golem cannot draw new ones yet.
